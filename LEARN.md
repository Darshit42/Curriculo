## Orientation

`curriculo` — Turn any Git repository into a guided, interactive course with code-grounded quizzes and a committable LEARN.md. Execution starts in `engine/index.js`, `cli/index.js`. This course walks through 4 lessons, from entry points to the most-imported modules.

## 3. `engine/`: `offline.js`, `llm.js`, `synth.js`, `prompts.js`

**Files:** [`engine/offline.js`](engine/offline.js) · [`engine/llm.js`](engine/llm.js) · [`engine/synth.js`](engine/synth.js) · [`engine/prompts.js`](engine/prompts.js)

Understand what engine/ is responsible for.

**`engine/offline.js`** — 220 lines (imported by ~2 files, core directory). Heuristic course generation with no model calls. Used by `--offline`, as the outline fallback when the model's outline is unusable, and as the degraded body for a lesson whose synthesis failed.
Key definitions: `readmeBlurb` (engine/offline.js:17), `projectDescription` (engine/offline.js:35), `groupKey` (engine/offline.js:58), `chunk` (engine/offline.js:65), `offlineOutline` (engine/offline.js:74), `languageMix` (engine/offline.js:123).

**`engine/llm.js`** — 141 lines (imported by ~2 files, core directory).
Key definitions: `BudgetError` (engine/llm.js:5), `configFromEnv` (engine/llm.js:16), `missingConfig` (engine/llm.js:24), `sleep` (engine/llm.js:32), `BharatCodeClient` (engine/llm.js:38), `extractText` (engine/llm.js:126).

**`engine/synth.js`** — 136 lines (imported by ~1 file, core directory). Model-backed course synthesis: outline -> lessons (parallel) -> quizzes. Every response is validated; a bad response is retried once, then the lesson degrades to a file list without a quiz instead of failing the run.
Key definitions: `callValidated` (engine/synth.js:15), `validateOutline` (engine/synth.js:27), `cleanBody` (engine/synth.js:46), `validateBody` (engine/synth.js:56), `validateQuiz` (engine/synth.js:65), `synthesizeWithModel` (engine/synth.js:74).

**`engine/prompts.js`** — 87 lines (imported by ~1 file, core directory). The three-step prompt chain: repo summary + outline, lesson synthesis, quiz generation. Every prompt sees only a ranked, budgeted slice of the repo.
Key definitions: `outlinePrompt` (engine/prompts.js:11), `lessonPrompt` (engine/prompts.js:41), `quizPrompt` (engine/prompts.js:65), `retrySuffix` (engine/prompts.js:84).

Suggested reading order: `offline.js` → `llm.js` → `synth.js` → `prompts.js`.
